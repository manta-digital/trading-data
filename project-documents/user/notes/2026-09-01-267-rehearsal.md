# Slice 267 rehearsal — throwaway database on the test cluster

Task file part 2, Section 9, run 2026-09-01 13:51 → 17:31 UTC against
a throwaway database `mt_rehearsal_267_41c53da1` created on the test cluster
(917) from `MT_TIMESCALE_TEST_URL`. The production URL never entered any child
environment: a driver script ran from a scratch directory with no `.env` and
passed only the throwaway URL as `MT_TIMESCALE_DB_URL` /
`MT_TIMESCALE_MAINTENANCE_URL` per command. Live Kalshi public API throughout
(300 req/min, so the historical cap was **9,000** — Decision 2's public
figure). Every figure below is quoted from the driver's per-pass logs
(`passN.log`, stderr with UTC stamps), the `--json` summaries (`passN.json`)
and `mt data kalshi status --json` after each pass. Times are UTC.

**Two substitutions, recorded up front.**

1. **The archive walk was not run to its stop point.** One capped firing walked
   3,895 pages (3.9 M markets, 10.1 GB) and reached 2026-03-31; the remainder
   (~3,000 pages, another ~8 GB) would have doubled a throwaway database on a
   cluster whose disk this rehearsal could not see, so after a second firing
   had **resumed the walk from the saved cursor for 200 pages** (the resume
   proven on a real database), the walk was hand-finished:
   `UPDATE kalshi.sync_state SET cursor = NULL, watermark_ts = <live floor>,
   coverage_from_ts = '2026-01-01' WHERE surface = 'historical'` — exactly the
   row the walk's completion plus the trades step's `init_state` would have
   left. The walk's size is the measurement in *Pass 1*; its completion is
   proven at the unit tier (`test_historical_sync.py` cases 13–15) and by the
   first production firing (cutover report).
2. **The live trades row was seeded before pass 1** as production has it
   (`watermark_ts = coverage_from_ts = trades_created_ts` of the cutoff,
   `2026-07-03T00:00Z`) — identical to what the trades phase's first run
   writes, so no separate warm-up pass was spent; pass 1 is both Task 9.1's
   pass and Task 9.2's first measured firing.
