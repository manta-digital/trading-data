## 3. pg_hba.conf

Read via `pg_hba_file_rules` with the maintenance credential (the file itself
is root-readable only; the view reflects the file as currently loaded).

| Question | Answer |
|---|---|
| Any `replication` line matching `trading_migrate`? | **Yes, from localhost only**: line 140 (`host replication all 127.0.0.1/32 scram-sha-256`) and line 141 (same for `::1`) admit any role, including `trading_migrate`, with a password. Line 139 (`local replication all peer`) requires an OS user matching the role name, so it does not apply to `trading_migrate`. |
| From remote hosts (e.g. 192.168.1.x)? | **No.** Lines 128–131 grant `{all}` *databases* on the LAN, but the `replication` keyword is matched only by explicit `replication` lines — none exists for any non-localhost address. `pg_basebackup` must run on `.144` itself, or a line must be added. |
