# 140 Slice-Plan Impact (Simplification Proposal)

Companion: [2026-05-03-data-pipeline-simplification.md](2026-05-03-data-pipeline-simplification.md)

This doc walks slice-by-slice through how the simplification proposal
(four changes summarized below) affects the existing 140 slice plan
and what the updated plan should look like.

**Proposal summary:**
1. **Long-running daemon** with quota-aware throttling
1a. **Named symbol lists** (`--list NAME`; suggested defaults: priority1 hand-set, priority2 = SP500 snapshot)
2. **`mt data ca` command group** (`update`, `show`, `list`) — bulk endpoint for steady-state, per-symbol for backfill
3. ~~Drop stored `adj_*` in favor of view-computed adjusted prices~~ — **WITHDRAWN** (breaks cagg correctness across ex-date boundaries)
4. **Backtest dir + MarketDB cleanup** (new slice 151)

### Slice 146 — CA detection loop + bulk EOD steady-state — **REFRAME**

**Original scope:** snapshot-drift detection inside the cycle (writes
new `adj_*` via band UPDATE) + bulk-EOD steady-state path.

**Under proposal:** this slice absorbs the **long-running daemon (#1)**,
**named symbol lists (#1a)**, and the **`mt data ca` command group
(#2)**. The original snapshot-drift detection and band-based `adj_*`
recompute remain — they're correct and necessary for cagg
consistency.

**Reframed slice 146 scope:**
1. **Long-running daemon mode** (`mt data daemon run`) with token-bucket
   throttling against `EODHD_PER_MINUTE_BURST` and `EODHD_DAILY_QUOTA`.
   Continuous loop. Graceful shutdown. Per-cycle progress reporting.
   Termination defaults: `--symbols X` and `--list NAME` exit when
   their scope is done; bare invocation runs forever. Override flags:
   `--forever` and `--stop-when-done`.
2. **Named symbol lists** — list config at `config/symbol-lists.yaml`
   (or `symbol_lists` table); `--list NAME` flag on the daemon
   restricts the cycle to that list's symbols. New CLI:
   `mt data lists ls`, `mt data lists show NAME`,
   `mt data lists refresh-sp500` (10 credits to
   `/fundamentals/GSPC.INDX`) refreshes the SP500 source file.
   Lists are operator state, not instrument state — no column on
   `instruments`. Lists also serve future uses: sector slices,
   watchlists, custom test sets.
3. **Bulk EOD steady-state** (`/eod-bulk-last-day/US`) for daily once
   caught up. 100 credits/cycle vs 12,636. Per-symbol `/eod` retained
   for backfill and refetch.
4. **`mt data ca` command group**:
   - `ca update` — defaults to yesterday's bulk splits + dividends
     across the entire exchange (200 credits). `--since N` extends
     to a per-day catchup range. `--symbol X` switches to per-symbol
     full-history backfill. `--list NAME` does per-symbol backfill
     across each member of the named list. `--symbol` and `--list`
     are mutually exclusive.
   - `ca show --symbol X` and `ca list --from --to` for inspection.
   - No `--type` flag (splits + dividends always paired). No
     `--date YYYY-MM-DD` for single historical days (no real
     workflow).
   - **Deletes legacy `mt data adjustment ingest`** (verified
     2026-05-03 to be fully covered by `ca update --symbol X
     [--since DATE]`). The `adjustment` Typer sub-app has only this
     one command and can be removed entirely.
5. **CA-drift detection + band-based `adj_*` recompute** (the original
   146 scope, retained). When new CAs land in `splits`/`dividends`
   (via `ca update`), the next daemon cycle compares the current
   `snapshot_id` to `acquisition_state.last_adjusted_ca_snapshot_id`;
   on mismatch, runs band-based UPDATE of `k_factor` AND `adj_*` for
   affected ex-date ranges, then refreshes affected cagg ranges.

**Effort:** 3/5 (unchanged). Code is larger than the original 146
because of the long-running daemon and `ca` command group, but the
adjustment-correctness machinery is unchanged.

**Verifiable:**
- Daemon runs continuously, throttles to stay under quota, finishes
  a single-symbol backfill (`--symbols SPY`) in <2 minutes and exits.
- Bare `mt data daemon run` runs indefinitely, processing the
  universe with quota awareness.
- Bulk-EOD path used in steady-state (verified by API call accounting:
  daily-pipeline credits drop from ~Nsymbols to ~100 once caught up).
- `mt data ca update` (no flags) fetches and upserts yesterday's
  splits + dividends; total CA pipeline cost is 200 credits/day.
- New CA arriving in the DB triggers band-based `adj_*` recompute on
  the next daemon cycle for affected ranges; affected cagg ranges
  are refreshed; reading the cagg returns the updated adjusted price.
